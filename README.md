## AI-Based Image Captioning System
The Image Captioning System is a web‑based application that automatically generates captions for 
uploaded images using a deep learning model. The system allows users to upload an image and 
receive a natural language description of the image. 

System Features

Image Upload(FR1) 
The system shall allow users to upload image files. The system shall accept images in JPG or 
PNG format and display the uploaded image.

Caption Generation (FR2) 
The system shall automatically generate captions using a deep learning model. The caption shall 
describe objects or activities present in the image.

Caption Display (FR3) 
The system shall display the generated caption clearly below the uploaded image.

Caption Storage(FR4) 
The system shall store generated captions in the Mongo DB database including image name, 
generated caption, and timestamp.

Caption History(FR5) 
The system shall allow users to view previously generated captions.

Delete Caption Record(FR6) 
The system shall allow users to delete stored caption records.
